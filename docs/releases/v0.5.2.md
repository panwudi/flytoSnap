# flytoSnap 0.5.2

## 简体中文

- 修复滚动截图只拼接一次就停止的问题. 选区内的固定页头, 工具栏和底部输入框不再打断拼接, 结果中只保留一份.
- 滚动过快丢失重叠时, 往回滚动一点即可在已拼接内容中重新定位并继续, 不再一直提示未找到重叠内容.
- 列表, 表格等重复内容在无法确定位置时会提示, 不再拼到错误位置.
- 滚动截图只采集选区, 采集间隔缩短, 拼接计算更快, 手动快速滚动更不容易丢失.
- 自动滚动的步长按实际滚动区域计算.
- 需要 Apple Silicon 和 macOS 14+. 使用 Developer ID 和 Ed25519 更新签名, 尚未通过 Apple 公证.

## 繁體中文

- 修正捲動截圖只拼接一次就停止的問題. 選取區域內的固定頁首, 工具列和底部輸入框不再中斷拼接, 結果中只保留一份.
- 捲動過快遺失重疊時, 往回捲動一點即可在已拼接內容中重新定位並繼續.
- 清單, 表格等重複內容在無法確定位置時會提示, 不再拼到錯誤位置.
- 捲動截圖只擷取選取區域, 擷取間隔縮短, 拼接計算更快.
- 自動捲動的步長依實際捲動區域計算.
- 需要 Apple Silicon 與 macOS 14+. 使用 Developer ID 與 Ed25519 更新簽章, 尚未通過 Apple 公證.

## English

- Fixes scrolling capture stopping after the first stitch. Sticky headers, toolbars, and bottom input bars inside the selection no longer break stitching and appear once in the result.
- After scrolling too fast, scrolling back a little relocates the view in the stitched content and resumes the capture.
- Repeated content such as lists and tables is rejected with a prompt when its position is ambiguous, instead of being stitched in the wrong place.
- Scrolling capture now captures only the selection, samples more often, and stitches faster.
- Automatic scrolling steps are sized to the moving region.
- Requires Apple Silicon and macOS 14+. Developer ID signed with Ed25519 update signatures; not yet Apple notarized.
