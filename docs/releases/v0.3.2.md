# flytoSnap 0.3.2

## 简体中文

- 修复点击截图工具栏或菜单时, 临时失焦导致选区被自动取消的问题.
- 打开状态栏菜单时保留选区; 确认切换到其他普通应用时仍会收起截图.
- 增加全屏选区, 大窗口选区, 工具按钮, 颜色按钮和菜单焦点的原生回归检查.
- 需要 Apple Silicon 和 macOS 14+. 使用 Developer ID 和 Ed25519 更新签名, 尚未通过 Apple 公证.

## 繁體中文

- 修復按一下截圖工具列或選單時, 暫時失去焦點導致選取區域被自動取消的問題.
- 開啟選單列選單時保留選取區域; 確認切換至其他一般應用程式時仍會收起截圖.
- 新增全螢幕選取區域, 大視窗選取區域, 工具按鈕, 顏色按鈕與選單焦點的原生回歸檢查.
- 需要 Apple Silicon 與 macOS 14+. 使用 Developer ID 與 Ed25519 更新簽章, 尚未通過 Apple 公證.

## English

- Fixes capture selections being canceled when toolbar or menu interactions temporarily change focus.
- Preserves the selection while the status menu is open, while still dismissing capture on a confirmed switch to another regular app.
- Adds native regression checks for full-screen and large selections, tool and color buttons, and menu focus.
- Requires Apple Silicon and macOS 14+. Developer ID signed with Ed25519 update signatures; not yet Apple notarized.
