# flytoSnap 0.5.1

## 简体中文

- 状态栏换用彩色 B2 取景器图标, 与应用图标, 设置和关于页面保持一致. 菜单标题与截图顶部菜单也显示同一图标.
- 顶部模式菜单可以拖动: 拖动图标旁的手柄, 或按住任意模式按钮移动. 轻点按钮仍正常切换模式.
- 菜单拖动时保持选框, 切换模式后保持位置, 并限制在屏幕范围内. 独立的菜单视图避免与标注工具栏重叠时被遮挡.
- 拖动手柄显示手形光标, 支持拖动过程中按 Esc 完整取消截图.
- 新增原生拖动, 点击, 重叠层级和取消回归检查, 更新十种语言的实际界面截图.
- 需要 Apple Silicon 和 macOS 14+. 使用 Developer ID 和 Ed25519 更新签名, 尚未通过 Apple 公证.

## 繁體中文

- 選單列改用彩色 B2 取景器圖示, 與應用程式圖示, 設定和關於頁面一致. 選單標題與截圖頂部選單也顯示相同圖示.
- 頂部模式選單可透過圖示旁的拖曳區域或任意模式按鈕移動. 輕點仍正常切換模式.
- 拖曳時保留選取區域, 切換模式後保留位置, 並限制在螢幕範圍內. 獨立選單視圖避免與標註工具列重疊時被遮住.
- 拖曳區域顯示手形游標, 拖曳過程中可按 Esc 完整取消截圖.
- 新增原生互動回歸檢查, 更新十種語言的介面截圖.
- 需要 Apple Silicon 與 macOS 14+. 使用 Developer ID 與 Ed25519 更新簽章, 尚未通過 Apple 公證.

## English

- Uses the color B2 viewfinder in the menu bar, matching the application icon, Settings, and About. The menu heading and capture mode menu show the same artwork.
- Makes the top mode menu draggable from its handle or any mode button. A click still switches modes normally.
- Preserves the selection and menu position across mode changes, constrains the menu to the screen, and keeps it above overlapping annotation controls.
- Adds hand cursors for dragging and supports Escape cancellation while tracking a drag.
- Adds native drag, click, overlap, and cancellation regression checks, and refreshes screenshots in all ten languages.
- Requires Apple Silicon and macOS 14+. Developer ID signed with Ed25519 update signatures; not yet Apple notarized.
