# flytoSnap 0.3.0

## 简体中文

- 新增应用内检查更新和自动下载, 退出时安装更新. 正在截图或录屏时延后安装.
- 更新包及更新订阅源使用 Ed25519 签名, 应用使用 Developer ID 签名.
- 仓库首页增加明显的三语言文档入口和对应截图.
- 需要 macOS 14+ 和 Apple Silicon. 0.2.x 需手动安装本版一次, 此后可在应用内更新.
- 当前包尚未通过 Apple 公证.

## 繁體中文

- 新增應用程式內檢查更新與自動下載, 結束時安裝更新. 截圖或錄影期間延後安裝.
- 更新包與更新訂閱源使用 Ed25519 簽章, 應用程式使用 Developer ID 簽署.
- 儲存庫首頁加入明顯的三語言文件入口與對應截圖.
- 需要 macOS 14+ 與 Apple Silicon. 0.2.x 需手動安裝本版一次, 之後可在應用程式內更新.
- 目前發行包尚未通過 Apple 公證.

## English

- Adds in-app update checks and automatic downloads, with installation on quit. Installation waits during capture or recording.
- Update archives and feeds use Ed25519 signatures. The app is Developer ID signed.
- Adds prominent documentation links and matching screenshots for all three languages.
- Requires macOS 14+ and Apple Silicon. Install this version manually once when upgrading from 0.2.x.
- This release is not yet Apple notarized.
