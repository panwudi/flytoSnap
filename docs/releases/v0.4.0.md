# flytoSnap 0.4.0

## 简体中文

- 支持截取 flytoSnap 自身的设置, 关于和贴图窗口. 仅排除捕获遮罩和滚动控制条.
- 新增日语, 俄语, 法语, 西班牙语, 葡萄牙语, 德语和韩语, 共十种界面语言.
- 更新窗口跟随应用内语言设置, 补齐 Sparkle 缺少的翻译.
- 新增关于窗口, 显示版本, 构建号, 作者, 版权和可打开的项目与许可证地址. 设置页与菜单也显示版本.
- 根据实际文字宽度调整模式栏, 滚动启动按钮与快捷键提示, 改善长文案显示.
- GitHub 增加七种语言的简明指南和对应界面截图.
- 需要 Apple Silicon 和 macOS 14+. 使用 Developer ID 和 Ed25519 更新签名, 尚未通过 Apple 公证.

## 繁體中文

- 支援擷取 flytoSnap 本身的設定, 關於和貼圖視窗. 僅排除擷取遮罩與捲動控制列.
- 新增日語, 俄語, 法語, 西班牙語, 葡萄牙語, 德語和韓語, 共十種介面語言.
- 更新視窗跟隨應用程式內的語言設定, 補齊 Sparkle 缺少的翻譯.
- 新增關於視窗, 顯示版本, 建置編號, 作者, 版權及可開啟的專案與授權連結.
- 改善長文案排版, 增加七種語言的 GitHub 簡明指南與對應介面截圖.
- 需要 Apple Silicon 與 macOS 14+. 使用 Developer ID 與 Ed25519 更新簽章, 尚未通過 Apple 公證.

## English

- Capture flytoSnap's own Settings, About, and pinned-image windows. Only capture overlays and scrolling controls are excluded.
- Add Japanese, Russian, French, Spanish, Portuguese, German, and Korean, bringing the interface to ten languages.
- Make update dialogs follow the in-app language selection and fill missing Sparkle translations.
- Add About with version, build, author, copyright, project, and license links. Show the version in Settings and the menu bar menu.
- Size mode tabs, scrolling start controls, and shortcut hints to their translated text.
- Add seven localized GitHub quick guides with matching native interface screenshots.
- Requires Apple Silicon and macOS 14+. Developer ID signed with Ed25519 update signatures; not yet Apple notarized.
