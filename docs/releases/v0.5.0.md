# flytoSnap 0.5.0

## 简体中文

- 换用奶白珐琅取景器图标, 内含雾蓝底板, 奶白浮雕云和橙色实体按钮.
- 统一截图工具栏, 模式栏, 设置, 关于, 录屏, 长截图和文字提取窗口的轻拟物风格.
- 奶白面板, 深蓝灰模式栏和橙色主要按钮增加柔和边缘, 浅凹槽, 悬停与按压反馈.
- 保留原生复选框, 文本编辑, 选区光标与十种语言支持. 标注色板保持独立, 避免界面材质覆盖颜色.
- GitHub 各语言指南同步更新实际界面截图.
- 需要 Apple Silicon 和 macOS 14+. 使用 Developer ID 和 Ed25519 更新签名, 尚未通过 Apple 公证.

## 繁體中文

- 換用奶白琺瑯取景器圖示, 內含霧藍底板, 奶白浮雕雲和橙色實體按鈕.
- 統一截圖工具列, 模式列, 設定, 關於, 錄影, 捲動截圖與文字擷取視窗的輕擬物風格.
- 奶白面板, 深藍灰模式列與橙色主要按鈕新增柔和邊緣, 淺凹槽, 懸停與按壓回饋.
- 保留原生核取方塊, 文字編輯, 選取區域游標和十種語言支援. 標註色板維持獨立顯示.
- GitHub 各語言指南同步更新實際介面截圖.
- 需要 Apple Silicon 與 macOS 14+. 使用 Developer ID 與 Ed25519 更新簽章, 尚未通過 Apple 公證.

## English

- Introduces an ivory enamel viewfinder icon with a mist-blue panel, cream relief clouds, and an orange physical button.
- Applies a restrained skeuomorphic style across capture toolbars, mode selection, Settings, About, recording, scrolling capture, and text extraction.
- Adds cream surfaces, slate mode controls, orange primary actions, subtle edges, recessed inputs, and hover and press feedback.
- Preserves native checkboxes, editable text, selection cursors, and ten interface languages. Annotation swatches remain independent of surface styling.
- Updates localized GitHub guides with current interface screenshots.
- Requires Apple Silicon and macOS 14+. Developer ID signed with Ed25519 update signatures; not yet Apple notarized.
